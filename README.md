## Engineering focus

- **Frontend & product:** React, Next.js, TypeScript, responsive UI, accessibility, and PWA behavior.
- **Backend & APIs:** Node.js, Express, REST, validation, authentication, authorization, and predictable error handling.
- **Data & asynchronous systems:** PostgreSQL, Prisma, MongoDB, Mongoose, Redis, BullMQ, caching, queues, and durable background work.
- **Quality & delivery:** Jest, Supertest, GitHub Actions, CI/CD, security checks, observability, health/readiness, and deployment.

## Engineering approach

**Clear boundaries.** Transport, validation, business rules, persistence, and background work should have obvious ownership.

**Failure modes matter.** Reliable software accounts for retries, stale state, dependency failure, authorization, partial completion, and degraded runtime behavior.

**Verification ships with the work.** Typechecking, tests, build checks, security checks, runtime probes, and live QA are part of delivery.
